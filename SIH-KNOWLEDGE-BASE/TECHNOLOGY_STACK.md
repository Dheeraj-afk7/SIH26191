# Technology Stack: SIH26191

## Technology Stack Inventory Table

| Technology | Category | Where It Is Used | Why It Was Chosen | Alternatives Considered (Documented) |
| :--- | :--- | :--- | :--- | :--- |
| **Python 3.10+** | Programming Language | Core backend API, spatial processing pipelines, validation scripts, test suite. | Rich ecosystem for scientific computing, raster analysis, and geospatial data processing. | C++ (higher development overhead for GIS scripting); R (less suited for production web APIs). |
| **FastAPI** | Backend Framework | `backend/main.py`, 12 modular route controllers (`backend/api/routes/`). | High performance (ASGI), native asynchronous support, automatic OpenAPI/Swagger documentation generation, strict Pydantic type validation. | Flask (synchronous, lacks automatic OpenAPI docs); Django (unnecessary monolithic ORM overhead for static spatial files). |
| **Uvicorn** | ASGI Web Server | Backend production server execution and development hot-reloading. | Lightning-fast ASGI server implementation for Python based on `uvloop` and `httptools`. | Gunicorn standalone (lacks native async event loop without Uvicorn workers). |

| **GeoPandas** | Spatial Vector Library | `backend/services/data_loader.py`, `processing/exposure/`, `processing/priority/`. | Industry-standard tabular spatial operations, spatial joins, coordinate reprojections, and R-tree spatial indexing (`sindex`). | GDAL Python bindings direct (too low-level and verbose for tabular attributes). |

## Explicitly Excluded Technologies (Architectural Constraint Enforcement)

| Excluded Technology | Justification for Exclusion |
| :--- | :--- |
| **PostgreSQL / PostGIS** | Unnecessary server overhead for district-scale dataset ($653$ villages, $289$ red zones). In-memory GeoPandas cache delivers sub-millisecond response times without database administration. |
| **GeoServer / MapServer** | Heavy Java/C++ server dependencies; GeoJSON served directly via FastAPI is significantly more agile and container-friendly. |
| **Kafka / Celery / Redis** | Heavy message-broker infrastructure; standard Python asynchronous threading and subprocess invocation satisfy Hackathon dynamic recomputation requirements. |
| **Uninterpretable Neural Networks (PyTorch / TensorFlow / Scikit-Learn)** | Black-box opacity violates scientific integrity standards for safety-critical hazard designations and community relocation planning. |
| **Commercial Paid APIs (Mapbox, Google Maps, ArcGIS Online)** | Violates open-source, reproducible government deployment principles. |
