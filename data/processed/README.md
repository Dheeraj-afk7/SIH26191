# data/processed/ — Intermediate Processing Outputs

This directory holds **intermediate GIS outputs** produced by the `processing/` pipeline scripts.
These files are derived from `data/raw/` and serve as inputs to subsequent pipeline modules.

## What belongs here

- Reprojected / clipped rasters (e.g., DEM clipped to district boundary)
- Derived terrain layers: slope, aspect, curvature, TWI, flow accumulation (GeoTIFF)
- Landslide Susceptibility Index raster (GeoTIFF)
- Flood Exposure Score raster (GeoTIFF)
- Multi-Hazard Index raster (GeoTIFF)
- Intermediate vector layers (GeoJSON / Shapefile)
- Joined habitation tables (CSV / GeoJSON)

## Rules

- Files here are **reproducible** — they can always be regenerated by re-running `processing/` scripts from `data/raw/`.
- Do not manually edit files here. They are machine-generated.
- All outputs must include their source module and parameters in their filename or an accompanying `.json` metadata sidecar.

## Expected file types

`.tif` `.tiff` `.geojson` `.csv` `.json`

## Git tracking

**Intermediate outputs are NOT committed to Git.** This directory's contents are excluded via `.gitignore` (`data/processed/**`).
Only this `README.md` is tracked to preserve directory intent.
Regenerate contents by running the processing pipeline on locally acquired raw data.

## Pipeline role

```
data/raw/  →  processing/*  →  data/processed/  →  processing/*  →  data/outputs/
```
